# VibePlan AI - 바이브 코딩 기획/설계 AI 비서

구글의 최신 **Gemini 3.5 API**를 연동하여 사용자의 간단한 한 줄 아이디어를 고도화하고, 3가지 추천 앱 컨셉을 제공하며, 최종 선택된 아이디어에 대해 상세한 시스템 설계서와 **Cursor/Gemini용 개발 프롬프트**를 즉시 추출해 주는 자동 기획 설계 비서 프로그램입니다.

## 주요 기능
- **아이디어 3대 컨셉 추천**: 키워드 하나로 성격이 다른 3가지 앱 아이디어 제안.
- **Vibe Check (기획서)**: 서비스 개요, 주요 타겟 고객, Pain Point 분석.
- **Blueprint (DB/시스템 설계)**: 관계형 데이터베이스 스키마(표) 및 흐름 설계.
- **User Flow (화면 설계)**: 화면 목록 및 해당 페이지 컴포넌트 구조 기획.
- **AI Prompt Guide (바이브 코딩 가이드)**: Cursor 및 Gemini에 복사해 즉시 코딩을 지휘할 수 있는 4단계 정교한 프롬프트 자동 조립.
- **사이버펑크 네온 글래스모피즘 UI**: 힙한 해커 워크스페이스 컨셉의 세련된 디자인.
- **구글 클라우드 Run 배포 지원**: 클릭 한 번으로 나만의 인터넷 주소 서버 배포 완료.

## 로컬 실행 방법

1. **의존성 설치**:
   ```bash
   pip install -r requirements.txt
   ```

2. **애플리케이션 실행**:
   ```bash
   python app.py
   ```
   실행 후 브라우저에서 [http://127.0.0.1:5000](http://127.0.0.1:5000)으로 접속하세요.

3. **Gemini API 연동**:
   - 우측 상단 혹은 설정 메뉴에서 [Google AI Studio](https://aistudio.google.com/)에서 발급받은 **Gemini API Key**를 입력합니다.
   - 모델 드롭다운을 통해 `gemini-3.5-flash` 또는 `gemini-3.5-pro` 버전을 선택할 수 있습니다.

## 구글 클라우드 Run 배포 방법

이 프로젝트에는 구글 클라우드 서버리스 서비스인 **Cloud Run** 배포 가이드가 동봉되어 있습니다.

1. **Google Cloud CLI** 설치 및 로그인 (`gcloud auth login`).
2. 프로젝트 루트 폴더에 포함된 배포 스크립트를 실행합니다:
   - **Windows (명령 프롬프트)**: `deploy.bat` 실행
   - **macOS / Linux / Git Bash**: `chmod +x deploy.sh` 실행 후 `./deploy.sh` 실행
3. 본인의 구글 클라우드 프로젝트 ID를 입력하면 자동으로 도커 이미지 빌드와 서버 배포가 진행되며, 실시간 도메인 주소가 발급됩니다.
