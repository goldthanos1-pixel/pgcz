# Weather Dashboard (날씨 대시보드)

파이썬 Flask 백엔드와 현대적인 글래스모피즘(반투명 유리) UI 프론트엔드로 구현된 날씨 대시보드입니다.

## 주요 기능
- **글래스모피즘 UI**: 날씨 상태와 시간대에 따라 실시간으로 변하는 미려한 반투명 테마.
- **날씨 시뮬레이터**: 별도의 API 키 없이도 서울, 뉴욕, 런던 등 다양한 글로벌 도시의 날씨 데이터를 풍부하게 가상 생성하여 보여줍니다.
- **실시간 날씨 연동**: OpenWeatherMap API 키를 설정 모달을 통해 입력하여 실제 실시간 날씨 데이터로도 확인 가능합니다.
- **상세 메트릭 & 차트**: 시간대별 온도 변화 및 강수 확률을 영역 차트(Chart.js)로 볼 수 있으며, 자외선 지수, 바람 정보, 대기 질(AQI) 등 다양한 날씨 지표를 제공합니다.
- **즐겨찾기 및 단위 설정**: 자주 찾는 도시를 등록(로컬스토리지 저장)하고, 섭씨/화씨 단위를 토글할 수 있습니다.

## 실행 방법

### 1. Python 설치
이 프로젝트는 **Python 3.8 이상**이 필요합니다.
- 파이썬이 설치되어 있지 않다면, [Python 공식 홈페이지](https://www.python.org/downloads/)에서 설치 파일을 다운로드하여 설치해 주세요.
- **주의 (Windows)**: 설치 중 `Add Python to PATH` 옵션을 반드시 체크해 주세요.

### 2. 의존성 패키지 설치
터미널(또는 명령 프롬프트)을 열고 이 폴더로 이동한 후 아래 명령어를 실행하여 필요한 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

### 3. 애플리케이션 실행
설치가 끝나면 아래 명령어로 Flask 서버를 실행합니다:
```bash
python app.py
```

실행 후 브라우저에서 [http://127.0.0.1:5000](http://127.0.0.1:5000)으로 접속해 대시보드를 확인하세요!
